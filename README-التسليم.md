# ركيزة (Rakeza HR) — دليل التنفيذ والتشغيل

## ما الذي يعمل به المشروع

- تطبيق ويب تجريبي للتصميم يعمل من `npm run dev`، ونسخة سطح مكتب تعمل عبر Electron من `npm run dev:desktop`.
- عند فتح نسخة سطح المكتب لأول مرة، يختار المستخدم نمط الجهاز: مستقل، مضيف لقاعدة البيانات على شبكة الشركة، أو عميل يتصل بالمضيف.
- تُحفظ قاعدة SQLite ومرفقات الوثائق محلياً على جهاز المضيف في `%LOCALAPPDATA%\Rakeza HR\data`. لا يفتح العميل ملف قاعدة البيانات عبر الشبكة؛ يتصل بخدمة API على الجهاز المضيف.
- تتضمن النسخة الحالية تسجيل دخول متعدد الحسابات، أدواراً (مسؤول، موارد بشرية، مدير، مشاهدة)، وثائق المؤسسة والموظفين، مرفقات محلية، تنبيهات الانتهاء، التصدير، وسجل تدقيق.
- في نمط المضيف يعمل التطبيق في منطقة الإشعارات بعد إغلاق النافذة؛ اختيار «إنهاء» يوقف الخدمة، ولذلك يجب أن يبقى جهاز المضيف مشغلاً ومتصلاً بالشبكة كي تعمل الأجهزة العميلة.

## إعداد بيئة التطوير

1. ثبّت إصدار Node.js LTS على Windows.
2. افتح PowerShell في `D:\HR Project`.
3. نفّذ `npm install` مرة واحدة لتنزيل اعتماديات الواجهة والخادم وElectron وتجهيز SQLite الأصلي.
4. لتشغيل الواجهة في المتصفح: `npm run dev`.
5. لتشغيل تطبيق سطح المكتب أثناء التطوير: `npm run dev:desktop`.
6. لإنشاء مثبت Windows: `npm run package:desktop`. ينتج ملف التثبيت داخل مجلد `release`.

إذا ظهر `Fetch failed` عند أول تشغيل لElectron، اسمح بالاتصال بتنزيل محرك Electron الرسمي، ثم أعد `npm run dev:desktop` أو `npm run package:desktop`.

## إعداد المؤسسة والأجهزة

1. على الجهاز الذي سيحفظ بيانات الشركة، شغّل البرنامج واختر «مضيف قاعدة البيانات».
2. أدخل عنوان HTTPS للمضيف وحدد شهادة TLS ومفتاحها. ينبغي أن يطابق اسم العنوان الشهادة وأن تكون الشهادة موثوقة على أجهزة العملاء؛ لا تستخدم HTTP عبر الشبكة.
3. أكمل بيانات المؤسسة وأنشئ حساب المسؤول الأول بكلمة مرور لا تقل عن 12 حرفاً.
4. على كل جهاز آخر ثبّت البرنامج واختر «جهاز عميل»، ثم أدخل عنوان HTTPS نفسه. سجّل الدخول بحساب مستقل لكل مستخدم.
5. يمكن تشغيل جهاز واحد بوضع «مستقل» إذا لم تكن هناك حاجة لاتصال أجهزة أخرى.
6. أضف المستخدمين والأدوار من «الإعدادات ← حسابات المستخدمين». لا يوجد حد أجهزة مفروض في التطبيق حالياً؛ عدد الاتصالات العملي يعتمد على جهاز المضيف والشبكة.

## البيانات والنسخ الاحتياطي

- قاعدة البيانات: `%LOCALAPPDATA%\Rakeza HR\data\rakeza.sqlite`.
- المرفقات: `%LOCALAPPDATA%\Rakeza HR\data\documents`.
- النسخ الاحتياطية: مجلد `backups` داخل مسار البيانات؛ ينشئ المسؤول النسخة من «الإعدادات ← الخصوصية والتخزين». تتضمن النسخة ملف قاعدة البيانات ومجلداً منفصلاً للمرفقات.
- استعادة نسخة حالياً إجراء صيانة خارج التطبيق: أوقف البرنامج على المضيف، واستعمل `engineering/backend/scripts/restore-backup.cjs` لاستعادة ملف SQLite إلى مجلد البيانات، ثم أعد مجلد المرفقات المطابق من النسخة إلى `documents`. احتفظ بنسخة من البيانات الحالية قبل الاستعادة.
- قاعدة البيانات SQLite مناسبة لهذا التشغيل لأن الكتابة وملف القاعدة على مضيف واحد، بينما الأجهزة الأخرى تتعامل مع API. لا تضع ملف SQLite على مجلد شبكي مشترك ولا تفتحه من عدة أجهزة مباشرة.

## ملاحظات الإصدار

- مثبت Windows في هذه المرحلة غير موقّع رقمياً، ويحتاج توقيع شهادة ناشر قبل التوزيع التجاري على نطاق واسع.
- نمط المضيف يتطلب إعداد شهادة TLS موثوقة وفتح المنفذ `47820` في جدار حماية Windows للشبكة الداخلية. تتم إدارة قاعدة البيانات محلياً ولا يوجد اعتماد على سحابة خارجية.
- ملف SQLite غير مشفّر على مستوى قاعدة البيانات في هذا الإصدار؛ احمِ حساب Windows ومجلد البيانات باستخدام صلاحيات NTFS وBitLocker، ولا تخزن بيانات حقيقية قبل اعتماد هذه الضوابط.
- بعد `npm install`، يحتاج Electron إلى تنزيل محرك التشغيل الرسمي عند أول تشغيل/بناء. تعذر تنزيله في بيئة التطوير الحالية لأن الاتصال بـGitHub غير متاح؛ لذلك لم ينتج ملف تثبيت `.exe` هنا، رغم نجاح بناء الواجهة.
- لا تستخدم بيانات العرض التجريبية في تشغيل حقيقي. ابدأ بقاعدة فارغة وحسابات مستخدمين فعلية.
- ملف `engineering/erd.sql` مرجع تصميم PostgreSQL سابق؛ تشغيل سطح المكتب الحالي يستخدم مخطط SQLite الذي يُنشأ في `engineering/backend/src/database.cjs`.
- دليل الصورة والتحليل البصري والرموز والمخططات موجود في `docs/01-الملخص-والتحليل.md` و`design/`.

## البناء التالي

لإكمال جاهزية الإنتاج: توقيع المثبت، استعادة النسخ من الواجهة، اختبارات التزامن والنسخ والاسترداد، سياسة تحديث التطبيق، إعداد TLS أسهل للمضيف، ومراجعة الأدوار التفصيلية للعمليات المالية والوثائق الحساسة.
