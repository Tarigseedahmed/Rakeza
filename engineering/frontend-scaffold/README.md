# ركيزة (Rakeza HR)

تطبيق موارد بشرية ثنائي اللغة (عربي/إنجليزي) بواجهة React وTypeScript. يمكن تشغيل هذه الواجهة منفردة للتجربة، أو استخدامها ضمن نسخة سطح المكتب مع خدمة البيانات المحلية.

## تشغيل الواجهة التجريبية

من جذر المشروع `D:\HR Project` نفّذ `npm install` ثم `npm run dev`.

## تشغيل نسخة سطح المكتب أثناء التطوير

من جذر المشروع نفّذ `npm run dev:desktop`. في أول تشغيل اختر أحد الأنماط التالية:

- مستقل: قاعدة SQLite على هذا الجهاز.
- مضيف: يستضيف قاعدة البيانات وخدمة API المحلية لمستخدمي الشبكة؛ يتطلب HTTPS وشهادة TLS موثوقة.
- عميل: يتصل بخدمة المضيف عبر HTTPS.

توجد تعليمات تشغيل كاملة في `../../README-التسليم.md`.

## الوظائف الحالية

- تسجيل دخول محلي متعدد المستخدمين وأدوار حسابات أساسية.
- إدارة الموظفين والحضور والغياب والإجازات والرواتب والسلف والعقود والملفات والتقارير.
- وثائق المؤسسة ووثائق متعددة لكل موظف، مع ملفات مرفقة محفوظة على المضيف.
- تنبيهات صلاحية عند 45 و30 و15 و7 أيام، وإظهار الوثائق المنتهية.
- إضافة وتعديل وحذف وبحث وتصفية، وتصدير Excel، وتصدير PDF عبر الطباعة.
- واجهة عربية RTL وإنجليزية LTR، وصفحتا حول البرنامج والدعم.

## حدود مهمة

البيانات التجريبية في وضع المتصفح تحفظ في هذا المتصفح فقط. أما نسخة سطح المكتب فتستخدم SQLite محلية على المضيف وخدمة API للتواصل بين الأجهزة. ملف SQLite لا يُشارك مباشرة عبر الشبكة. النسخة الحالية أساس تشغيل داخلي وليست بعد حزمة إنتاج موقعة أو متضمنة استعادة نسخ احتياطية من الواجهة.
