# السعودية: ملف القواعد الأولي

**آخر مراجعة للمصادر:** 2026-11-10  
**نطاق النسخة:** القطاع الخاص، مرجع تقديري فقط  
**الحالة:** قواعد مرجعية محكومة بالمصدر؛ لا تعتمد كقرار رواتب أو استشارة قانونية.

## القواعد التي يغطيها البرنامج

| الموضوع | القاعدة المرجعية | الاستخدام الحالي |
|---|---|---|
| الإجازة السنوية | 21 يوماً سنوياً، وتصبح 30 يوماً بعد خمس سنوات متصلة لدى صاحب العمل. | endpoint يعيد الحد الأدنى حسب مدة الخدمة؛ الرصيد الفعلي يحتاج رصيداً مرحلاً وسياسة المنشأة والإجازات المستهلكة. |
| مكافأة نهاية الخدمة | نصف أجر شهر عن كل سنة من أول خمس سنوات، وأجر شهر عن كل سنة تالية، مع التناسب لجزء السنة. | تقدير عبر API فقط. يدعم انتهاء صاحب العمل والاستقالة؛ ويوقف/يتطلب مراجعة للسيناريوهات الأخرى. |
| ساعات العمل الإضافي | أجر الساعة مضافاً إليه 50% من الأجر الأساسي للساعة. | تقدير API إذا زُوّد بساعات وأجور الساعة بعد تحديد جدول العامل؛ لا يحول الساعات الشهرية إلى قانونية تلقائياً. |
| التأمينات - النظام السابق | 9% معاشات على الموظف و9% على المنشأة للسعودي، وساند 1% لكل طرف، والأخطار المهنية 2% على المنشأة. | تقدير API عند تأكيد الجنسية والسجل/البرنامج والأجر المسجل في التأمينات. |
| التأمينات - النظام الجديد | المشمولون الجدد فقط؛ إجمالي المعاشات 18% بدءاً ثم 19% من 2025-07-01 و20% من 2026-07-01 و21% من 2027-07-01 و22% من 2028-07-01، مقسمة بالتساوي. ساند 0.75% لكل طرف والأخطار المهنية 2% على المنشأة. | تقدير API مشروط بتأكيد GOSI scheme وأجر الاشتراك المسجل. |
| مواطنو دول الخليج وغير السعوديين | يخضعون لمعاملات وتغطية لا يمكن استنتاجها من اختيار الدولة فقط. | غير السعودي: يقدر فرع الأخطار المهنية 2% على صاحب العمل عند إدخال الأجر المسجل. مواطنو الخليج: مراجعة يدوية بسبب مد الحماية التأمينية. |

## واجهات التقدير

كل الواجهات تتطلب جلسة دخول وصلاحية قراءة الرواتب، وتعمل فقط إذا كان بلد المؤسسة `SA`. الاستجابة تضع `advisory: true` و`requiresHumanReview: true` ولا تحفظ مدخلات الرواتب. يسجل سجل التدقيق نوع التقدير ومعرف القاعدة فقط.

- `GET /api/compliance/profile` يعرض الدولة، تاريخ مراجعة الملف، القواعد ومراجعها.
- `POST /api/compliance/saudi/estimate` يقبل `{ "kind": "annualLeave", "startDate": "2020-01-01", "asOf": "2026-01-01" }`، أو `kind: "endOfService"` مع `startDate`, `endDate`, `lastMonthlyWage`, `terminationReason`، أو `kind: "overtime"` مع `hourlyWage`, `basicHourlyWage`, `overtimeHours`، أو `kind: "socialInsurance"` مع `nationality`, `confirmedGosiScheme`, `gosiCoveredMonthlyWage`, `payrollDate`.
- حالات متوقعة: `401` دون جلسة، `403` دون صلاحية الرواتب، `409` إذا كانت الدولة غير السعودية، `422` لمدخلات غير صالحة أو سبب إنهاء غير مدعوم، و`200` لتقدير توجيهي. بعض الحالات (مثل مواطني الخليج) تعيد `available: false` وسبب المراجعة بدلاً من مبلغ.

## قيود مقصودة

- تغيير الدولة لا يغيّر جنسية الموظف أو عضويته التأمينية.
- على المؤسسة إدخال مخطط التأمينات كما يظهر في سجل GOSI لكل موظف؛ تاريخ الالتحاق وحده لا يكفي لتصنيف الحالات الانتقالية.
- ناتج مكافأة نهاية الخدمة تقديري ولا يشمل حالات المادة 87، إنهاء المادة 80، القوة القاهرة، الوفاة، الحمل/الزواج، النزاع على مكونات الأجر، أو بنود العقد الأفضل.
- تقدير الاشتراكات يقبل أجر الاشتراك الذي تؤكده GOSI مباشرة؛ لا يحسب الأجر الخاضع بنفسه أو الحدود/التعديلات الاستثنائية.
- لا تُنشأ قيود رواتب أو تخصم مبالغ من الموظفين من هذه التقديرات. يلزم مراجعة بشرية واعتماد مسؤول الرواتب قبل الترحيل.
- النظام الحالي لا ينشئ ملفات WPS/Mudad ولا يرسلها إلى منصة خارجية. التكامل يحتاج اعتماد مواصفات الجهة ومفاتيح الخدمة واختبارات قبول منفصلة.
- هذه المراجعة ليست بديلاً عن مراجعة مختص سعودي. قبل استخدام فعلي للرواتب، راجعوا النسخة السارية من الأنظمة واللوائح وملف كل مشترك لدى GOSI، واحتفظوا بنسخة المصدر وتاريخ النفاذ.
